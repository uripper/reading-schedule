# Changes in 0.3.1-alpha

## Improvements

- Switching workspaces is faster: Bartleby no longer saves before switching when nothing changed, and it remembers your choice for next launch in the background.
- All Workspaces has been removed for now, so each workspace is always shown on its own.

## Fixes

- Fixed books being copied into the wrong workspace, or duplicated, after switching workspaces or using All Workspaces. Bartleby now refuses any save that would put a book in two workspaces.
- Fixed the workspace selector sometimes naming a different workspace than the one on screen.
- Fixed a save error that could not be dismissed: when saved data changed underneath the open workspace, Bartleby now reloads it instead.
- If opening a workspace fails partway, Bartleby returns to the previous workspace instead of mixing their books.
- Fixed a workspace sometimes skipping its replan after books were moved in or out, if Bartleby closed before planning finished.
