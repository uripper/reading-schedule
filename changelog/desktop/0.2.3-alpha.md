# Changes in 0.2.3-alpha

## Improvements

- Mass Edit can add a collection to, or remove one from, every selected book; collections only some of them share are left as they are.

## Fixes

- Collections changed in Mass Edit are now saved.
- In the Collections search, the first arrow press no longer skips the top or bottom suggestion.
- Planning stops after five centuries of days instead of running out of memory when a book's word count is impossibly large; the plan shows as incomplete.
- Planning with a high books-per-day limit is fast again.
