# Changes in 0.2.2-alpha

## New

- Collections: add a book to as many collections as you like, then filter the Library by collection. Each book still sits on one shelf.
- Book cards list the collections each book belongs to.

## Improvements

- Add Book and Edit Book have a new Bookshelf and Collections section; search for a collection or type a new name to create one, and remove it from the chips below.
- Library search also matches collection names.
- In Update progress, Update selected is now the first, green action before Select all and Deselect all.
- Kobo progress can now replace newer Bartleby progress when you check that book in Update progress; its reading time replaces Bartleby's too.
- Schedules are no longer capped at 10 years; the plan runs as long as your reading list needs.
- Planning large reading lists is much faster: a library of thousands of books now plans in about a second instead of a minute or more.

## Chores

- The planner benchmark now matches the app: no end date and 30 reading minutes a day by default.
