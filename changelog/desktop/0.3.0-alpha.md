# Changes in 0.3.0-alpha

## New

- Workspaces: keep separate libraries, planner settings, schedules, and stats for different purposes, like Career, Personal, or French; one daily goal covers them all. Switch from the workspace selector in the header on any tab; you stay on the same tab, and the last workspace you used reopens on launch.
- Manage workspaces in Settings → Workspaces: create one (optionally copying plan settings from another workspace, without its books), rename, archive, restore, or delete it. Deleting can move its books to another workspace first, and at least one workspace always remains.
- Move books between workspaces: in Library, turn on Mass Edit, select books, and choose a workspace from "Move to…", or pick a Workspace in Edit Book. Progress, status, deadlines, covers, and other book settings move with the book; reading history stays with the workspace where you read it; After Book links that would cross workspaces must be moved together or removed; and moves can be undone.

## Improvements

- A loading indicator now shows while Bartleby opens, switches workspaces, or moves books.
- Your existing data moves automatically into a default "My Reading" workspace, and a one-time backup of the previous data is kept as `planner_state.pre_workspaces.json` in the app data folder.
- Data exports and imports include every workspace.
- Saved data now uses format version 2; older Bartleby versions cannot open data saved by this version.
