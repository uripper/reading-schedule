# Changes in 0.1.9-alpha

## New

- Library search now matches keywords across title, author, shelf, status, lookup notes, due and finished dates, and page count. Hover the ? next to Search to see everything it searches.
- Paste an image (Ctrl+V) in the book dialog to set a custom cover.
- Finished books show their finished date on the card.

## Improvements

- Refreshed Library toolbar: icon buttons, a search field with a search icon, dropdown arrows, and a one-click ascending/descending sort toggle.
- Replaced the hand-drawn carousel arrows, streak flame, goal checkbox, edit/save buttons, and checkmarks with a consistent icon set.
- Clearer icons on book status labels.
- Custom covers are processed in the background, lowering the time it takes to save a book.
- Book search handles author names written in other scripts and common misspellings better.

## Fixes

- Removed the odd calendar glyph from the Est. Finish button.
- Projected finish dates in the Schedule no longer mark a book's progress as 100%.
