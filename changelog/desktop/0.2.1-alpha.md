# Changes in 0.2.1-alpha

## Chores

- Upgraded development tools and removed some unused code.

## Improvements

- Schedule cards made more compact.
- Buttons are redesigned.
- Add Book and Edit Book use larger text, higher-contrast fields, collapsible sections, and a live reading progress bar.
- Search Open Library from the book form with Enter or the search button.
- Today’s Add Book action fits alongside the book covers as a green tile.
- The calendar's Today button shows a "Jump to today" tooltip.
- No more splash screen on startup.
