# Changes in 0.2.1-alpha

## Chores

- Upgraded development tools and removed some unused code.

## Improvements

- Schedule cards made more compact.
- Buttons are redesigned.
- Add Book and Edit Book are wider and use higher-contrast fields, collapsible sections, and a live reading progress bar.
- App text starts at 16 px, and the desktop app defaults to 100% zoom.
- Search Open Library from the book form with Enter or the search button.
- Today’s Add Book action fits alongside the book covers as a green tile.
- Long book titles in the calendar grid end with an ellipsis after two lines.
- Date pickers are wider and keep month and year controls clear of the navigation buttons.
- The calendar's Today button shows a "Jump to today" tooltip.
- No more splash screen on startup.
- The desktop app icon now matches the Bartleby logo shown in the app.

## Fixes

- Screen readers announce the main tabs correctly, and the selected tab updates as you switch.
- The app opens faster: a lighter header logo, and the selected Today cover loads first.
