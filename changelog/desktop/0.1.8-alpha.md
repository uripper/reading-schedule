# Changes in 0.1.8-alpha

## New Features

- Library search now matches keywords across title, author, shelf, status, lookup notes, due and finished dates, and page count. Hover the ? next to Keyword to see everything it searches.
- Paste an image (Ctrl+V) in the book dialog to set a custom cover.
- Finished books show their finished date on the card.

## Improvements

- Clearer icons on book status labels.
- Custom covers are processed in the background, lowering the time it takes to save a book.
- Book search handles author names written in other scripts and common misspellings better.

## Fixes

- Removed the odd calendar glyph from the Est. Finish button.
- Projected finish dates in the Schedule no longer mark a book's progress as 100%.
