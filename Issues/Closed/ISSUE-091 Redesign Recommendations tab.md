# ISSUE-091: Redesign Recommendations tab

**Type:** enhancement
**Priority:** P2
**Labels:** `enhancement`, `ux`, `desktop`

Problem:

The Recommendations tab needs a broader design pass. The current presentation does not feel strong enough for discovery and add-to-library workflows.

Expected:

Recommendations has a clearer browsing structure, better ranking visibility, and stronger affordances for acting on results.

Definition of done:

- Redesign the Recommendations layout as a cohesive discovery surface.
- Improve hierarchy for query, result explanation, and add-to-library actions.
- Preserve current recommendation functionality unless explicitly changed.
- Add or update tests for any behavior changes introduced by the redesign.

Context:

- `electron/renderer/recommendations/`
- `electron/index.html`
