# ISSUE-028: Epic: UX Simplification and Cognitive Accessibility


**Type:** enhancement
**Priority:** P1
**Labels:** `enhancement`, `epic`, `ux`, `accessibility`, `desktop`

Problem:

Core workflows still require too many decisions across onboarding, daily execution, and settings complexity for users who need low-friction flows.

Expected:

UX simplification work is managed as an epic that keeps common actions short, predictable, and keyboard/focus safe.

Definition of done:

- Track dependent implementation issues for settings simplification, focus mode, onboarding streamlining, and reminder controls.
- Define usability outcomes for each dependent issue (fewer steps, fewer context switches, clearer next action).
- Require accessibility acceptance checks in each dependent issue.

- `ROADMAP.md`
- `ISSUES.md`
